# Permanent seat stickers and showtimes

1. Open `/maharaja` → Seat QRs. Save the verified screen and seats. Existing seat records retain their QR tokens when saved again.
2. Leave **Permanent seat stickers** selected, choose the configured screen, generate and print. These links contain a stable seat token, not a movie or show date. Keep the domain and seat records to keep stickers working.
3. Open **Movies & showtimes**. Review imported entries with the date filter or All dates. Add or edit the movie, screen, date, IST start time, runtime and active/withdrawn status.
4. A scan resolves the seat and the one currently running, fresh show on its screen. The page refreshes this context every 15 seconds. Checkout revalidates the seat token, screen, seat, show and ordering window on the server.

Ordering opens 15 minutes after the start and closes 30 minutes before the end. Late-night shows continue across midnight. Missing, stale, withdrawn or ambiguous schedules keep checkout closed. The cinema pause control still applies.

Manual edits are audited and reject overlapping shows on the same screen. Shows with existing orders cannot have their movie, screen or timing changed; withdraw the show and create a corrected entry if necessary. Withdrawal keeps order history and tracking.

Saving an imported entry changes it to manual management. The current importer refuses a date containing manual entries, requiring review rather than overwriting them. This feature does not schedule recurring BookMyShow imports: future schedules still need to be imported or entered.

Session Links and the optional show-specific QR mode remain available for temporary use. Use permanent seat stickers for fixed armrests.

Before printing all stickers, test one configured seat against a staging show: scan, check the displayed seat/movie, verify ordering before opening, during the window, and at cutoff, and complete a Razorpay test order through delivery.
